POUR LE METTRE SUR GITHUB
- Decompresser le fichier GITHUB.
- Ajouter le contenu decompresse dans ton depot : README.md et les dossiers.
- Sur le site GitHub : « Add file » puis « Upload files ».
  Le paquet est prepare pour moins de 100 fichiers et moins de 25 MiB
  par fichier. GitHub Desktop convient aussi.

Garder seulement le ZIP dans le depot empecherait de parcourir directement
les recherches et les sources sur GitHub.

Les deux archives ont un inventaire et leurs fichiers sont controles
un par un. Le fichier Gare-JC-VERIFICATION-2026-10-22.json, a cote des ZIP,
contient leurs tailles, nombres de fichiers et empreintes de verification.
