# Documentation moteur

Le catalogue moteur et les images de ses pages sont conservés dans l'archive
complète. La version GitHub conserve le lien vers la source :

[ASLONG, 37 mm Round Spur Gear Motor](https://www.aslongdcmotor.com/photo/aslongdcmotor/document/26547/37mm%20Round%20Spur%20Gear%20Motor_PDF00.pdf).

Ce document sert à vérifier les cotes d'une version de réducteur. La version
exacte du moteur et la charge radiale admissible ne sont pas validées.
